# Портфолио рабочих задач: ИИ-агент в инженерной сантехнике

Репозиторий описывает задачи, которые ИИ-агент (Hermes Agent) регулярно выполняет в работе отдела инженерных систем и продаж: сверка прайсов и выгрузок 1С, подготовка коммерческих материалов, мониторинг рынка, работа с документами и почтой.

Это не демонстрационные примеры, а описание реальных повторяющихся процессов. Каждая карточка построена одинаково: **задача → как решается → что получается на выходе → чем сделано**.

## Принципы работы

1. **Сначала подтверждение понимания.** Агент письменно фиксирует, как понял задачу, и ждёт подтверждения — до начала работы, а не после.
2. **Числа из таблиц не берутся на веру.** Для любого расчёта из выгрузки/прайса сначала прогоняется автоматический каркас проверки (суммы, количество строк, дубли, нули), и только потом числа попадают в решение.
3. **Второй контур проверки ответов.** Содержательные ответы проходят приёмку отдельным контрольным контуром; если проверка не отвечает, ответ отправляется с явной пометкой.
4. **Данные не уходят наружу без разрешения.** Передача, копирование или публикация любых рабочих данных — только с явного согласия владельца.
5. **Процедуры не держатся в голове.** Отработанные процессы записываются как переиспользуемые навыки с пошаговыми инструкциями и подводными камнями.

## Технический контур

- **Платформа:** Hermes Agent, несколько изолированных профилей (рабочий, настольный, контрольный).
- **Инструменты:** терминал, браузерное управление, Python, Excel (включая COM-автоматизацию), Word/PowerPoint, OCR, распознавание речи.
- **Планировщик:** регулярные задачи по расписанию — сбор новостей, ценовые сверки, отчёты.
- **Память:** устойчивые факты о процессе и среде хранятся отдельно от процедур, чтобы не смешивать контекст.

## Чего в репозитории нет

Клиентских данных, цен и коммерческих условий, выгрузок из 1С, персональных данных, ключей доступа. Все примеры обезличены: без названий контрагентов, артикулов и сумм.
