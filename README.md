## Четыре основных направления

### 1. Мониторинг рынка и конкурентов

Фиксированный список источников, сбор по расписанию, отбор значимых публикаций по конкретным продуктам, перевод иностранных материалов, дайджест со ссылками на первоисточники.

**Умения:** постановка задач ИИ-агенту, работа с API и открытыми источниками, фильтрация и перевод.

### 2. Онлайн-тестирование продукта

Агент проходит форму подбора как реальный пользователь — до скачивания чертежей, спецификации и коммерческого предложения. Дефекты описываются воспроизводимо: что ввёл, что ожидал, что получил.

**Умения:** тестирование по пользовательским сценариям, автоматизация браузера и веб-форм, описание дефектов.

### 3. Профильные знания: коллекторные узлы

ГОСТы и СП, каталоги, паспорта, пособия для проектировщиков: ответ строится только по этим документам и со ссылкой на источник. Переподбор аналогов SPL по артикулам конкурентов.

**Умения:** база знаний по нормативам, ответы с опорой на источник, подбор аналогов оборудования.

### 4. Автоматизация MS Office

Excel: сопоставление значений между таблицами по заданной логике, связи между книгами. PowerPoint: сборка и правка презентаций, корпоративный стиль по образцу.

**Умения:** формулы и связи между книгами, шаблоны и корпоративный стиль, автоматизация однотипных операций.

## Как контролируется качество

1. **Сначала подтверждение понимания.** Агент письменно фиксирует, как понял задачу, и ждёт подтверждения — до начала работы, а не после.
2. **Числа из таблиц не берутся на веру.** Для любого расчёта из выгрузки или прайса сначала прогоняется автоматическая проверка каркаса (суммы, количество строк, дубли, нули), и только потом числа попадают в решение.
3. **Второй контур проверки.** Содержательные ответы проходят приёмку отдельным контрольным контуром; если проверка не отвечает, ответ уходит с явной пометкой «проверка не выполнена».
4. **Проверка собственных действий.** После операции результат перечитывается по факту — файл открывается заново, страница перезагружается, число пересчитывается.
5. **Данные не уходят наружу без разрешения.** Передача, копирование или публикация рабочих данных — только с явного согласия владельца.
6. **Процедуры не держатся в голове.** Отработанные процессы записываются как переиспользуемые навыки с пошаговыми инструкциями и подводными камнями.

## Технический контур

- **Платформа:** Hermes Agent, несколько изолированных профилей (рабочий, настольный, контрольный).
- **Инструменты:** Python, Excel (включая автоматизацию через COM), Word и PowerPoint, браузерное управление, OCR, распознавание речи, работа с API.
- **Планировщик:** регулярные задачи по расписанию — сбор новостей, ценовые сверки, отчёты.
- **Память и навыки:** устойчивые факты хранятся отдельно от процедур, чтобы не смешивать контекст; процедуры — в переиспользуемых навыках.
